# Avārijas Brigāde — Guild Website

A responsive bilingual (Latvian/English) static website for the Avārijas Brigāde WoW guild.

## Publish with GitHub Pages (free)

1. Create a GitHub account if you do not already have one.
2. Create a **public** repository named `avarijas-brigade`.
3. Upload all files and folders from this package to the repository root:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `assets/favicon.svg`
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main`, folder `/ (root)`, then click **Save**.
7. Wait a few minutes. Your site should appear at:
   `https://YOUR-GITHUB-USERNAME.github.io/avarijas-brigade/`

## Before publishing

- In `index.html`, replace `YOUR-GITHUB-USERNAME` in the JSON-LD `url` with your actual GitHub username.
- Check the Discord invite is still valid: `https://discord.gg/bbRNztj4Y`.
- Confirm the current raid days, server wording, and loot rules with guild leadership before treating them as final.
- The site currently says exact raid start times are to be confirmed.

## Editing

- Edit text and metadata in `index.html`.
- Edit translations in `script.js`.
- Change visual styles in `styles.css`.
